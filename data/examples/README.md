# Учебный сценарий эксперимента

Все CSV в этой папке — синтетические иллюстративные данные, а не измерения реального транзистора. Они помогают пройти весь рабочий сценарий в UI, но не предназначены для оценки реальных технологий. Для MOS-структур кривые рассчитаны той же упрощённой аналитической зависимостью, которую использует экстрактор. Для них заложены `VTH0 = 0.42 В`, `U0 = 320 см2/(В·с)`, `NFACTOR = 1.45`, `tox = 5 нм`, `L = 0.18 мкм`, `T = 300 К`.

## Наборы для каждого семейства

| UI тип | Пример | Важные поля, совпадающие с образцом | Действие |
|---|---|---|---|
| Planar MOSFET | `idvg_vd_005.csv` | `W = 1 мкм` | Id–Vg fit; можно экспортировать BSIM4 |
| FD-SOI | `fd_soi_idvg.csv` | silicon body `7 нм`, BOX `25 нм`, back-gate `0 В` | Id–Vg MOS-приближение |
| FinFET | `finfet_idvg.csv` | fin `8 × 40 нм`, 2 fins, pitch `30 нм` | Id–Vg с эффективной шириной по периметру |
| GAA nanosheet | `gaa_nanosheet_idvg.csv` | sheet `30 × 8 нм`, 3 sheets, pitch `30 нм` | Id–Vg с суммарным периметром |
| GAA nanowire | `gaa_nanowire_idvg.csv` | 3 wires диаметром `10 нм` | Id–Vg с периметром провода |
| TFET | `tfet_idvg.csv` | tunnel `20 нм`, body `8 нм`, source/drain doping `1e20/1e18 см-3` | `VTH_CONSTANT_CURRENT`, `ION/IOFF`, SS, gm |
| HEMT | `hemt_idvg.csv` | AlGaN/GaN, barrier `20 нм`, 2DEG `1e13 см-2`, channel mobility `1500 см2/(В·с)` | Transfer metrics и JSON-отчёт |

Ещё доступны `idvg_vd_080.csv` для сравнения bias, `idvd_vg_080.csv` для выходных характеристик при фиксированном `Vg = 0.8 В` и `cv_sweep.csv` для учебной C–V оценки.

Для новых анализов Silvaco-style табличных файлов добавлены `silvaco_idvg.log`, `silvaco_igvg.log`, `silvaco_cv.log`, `bjt_gummel.log`, `bjt_output.log`, `ac_gains.log`, `transient_switching.log` и `gate_charge.log`. Все примеры можно загрузить одной кнопкой **Загрузить примеры** в UI. Выпадающий список над графиком показывает характеристики, доступные в загруженных данных, и позволяет переключать график; одинаковые характеристики из разных файлов отображаются вместе. Кнопка **Рассчитать все кривые** выводит метрики всех загруженных наборов в таблицу под графиком. Для собственных данных используйте **Импорт кривых** и выберите один или несколько файлов. Имена столбцов содержат типы величин, данные в примерах синтетические.

`example_transistor_channel.stl` — простой ASCII STL-пример прямоугольного канала. Импортируйте его кнопкой **Загрузить CAD STL** на вкладке **3D / Тепло / Поле** и выберите единицы `мм`. AutoCAD и КОМПАС-3D могут экспортировать пользовательскую геометрию в STL; для этого UI-просмотра доступны также бинарные STL-файлы. В диалоге импорта выберите `example_transistor_channel.json`, чтобы загрузить параметры модели; либо откажитесь и задайте их в форме вручную. JSON-параметры учебные и не откалиброваны. Расчётное поле отображается на геометрии, но CAD STL пока не задаёт FEM-объём.

## Быстрый запуск

1. Запустите приложение из корня проекта: `python -m src.main`.
2. Оставьте значения материала и геометрии по умолчанию. Они соответствуют параметрам, использованным при генерации образцов.
3. Нажмите **Импорт CSV** и выберите `idvg_vd_005.csv` из этой папки.
4. Выберите загруженную характеристику и нажмите **Рассчитать параметры**. Для чистых образцовых данных значения должны быть близки к `VTH0 = 0.42`, `U0 = 320`, `NFACTOR = 1.45`.
5. Импортируйте `idvg_vd_080.csv` и повторите экстракцию. Сравните результаты с низким напряжением стока; в реальных измерениях сравнение может показать короткоканальные и другие эффекты, которые эта простая модель не описывает.
6. Импортируйте `idvd_vg_080.csv` и рассчитайте `RON`, `gds`, `IDS_MAX` и gate bias.
7. Для каждого типа из таблицы переключите тип транзистора, задайте указанные структуру/материал и импортируйте соответствующий CSV. У TFET/HEMT анализируйте curve metrics; эти устройства не аппроксимируются BSIM4.
8. Импортируйте `cv_sweep.csv` и запустите расчёт. Будут показаны оценки `CGG`, `CGSO` и `CGDO`; это упрощённая оценка, а не полноценная калибровка BSIM4 по C–V.
9. Для planar MOSFET доступен экспорт `.model`; у других семейств кнопка сохраняет JSON-отчёт с входными данными и оценками. График сохраняется отдельно кнопкой **Сохранить график**.
10. Откройте вкладку **3D / Тепло / Поле**. Измените размеры транзистора в форме слева и убедитесь, что 3D-схема обновилась; включите вращение сцены.
11. Установите рабочую точку (например, `Vd = 0.8 В`, `Id = 100 мкА`), теплопроводность и толщину подложки, затем нажмите **Рассчитать тепло и поле**. Просмотрите температурную карту и электрическое поле через выпадающий список.

3D-расчёт выполняется FEM по тетраэдральной сетке с локальным сгущением около канала, затвора и границ слоёв; размер сетки можно менять в интерфейсе. CUDA-решатель использует FP64 и проверяет наличие свободной VRAM; при её нехватке выбирается CPU. Тепловая и электрическая модели используют упрощённые граничные условия, описанные в корневом README; магнитная карта рассчитывается аналитически. Результат предназначен для демонстрации влияния геометрии и рабочей точки, не для проектной верификации реального прибора.

Для проверки CSV и экстрактора из корня проекта выполните `python -m unittest discover -s tests -v`.

Форматы и единицы: напряжение — В, ток — А, ёмкость — Ф. CSV-файлы содержат заголовок; приложение само определяет разделитель из запятой, `;` или табуляции.

# Memristor, memtransistor, and neuristor examples

The CSV traces in this directory are generated by
`src.simulation.solve_memory_characteristics` and
`src.simulation.solve_neuristor_characteristics`. They are synthetic
demonstration data, not measurements or calibrated material parameters. The
memristor and memtransistor use a bounded, windowed ionic state model with
SET/RESET thresholds, activation-energy temperature scaling, and an initial
state. The memtransistor additionally uses the gate voltage to program its
state and to modulate channel conduction; its state relaxes when the gate is
between the programming thresholds.

The neuristor is a different device class: a **volatile** Mott threshold switch
(VO₂-like) that does not retain state. It self-resets below its hold voltage,
which is what lets a driven line emit repeating spikes instead of freezing in a
single resistive state.

| Files | Data | Load with device model |
|---|---|---|
| `memristor_iv_*.csv` | Pinched I-V loops at 10, 100, and 1000 V/s, with resistance, state, and time columns | `memristor_model.json` |
| `memristor_resistance_*.csv` | Resistance and state versus time for the matching voltage sweeps | `memristor_model.json` |
| `memtransistor_idvg_*.csv` | Forward/reverse Id-Vg sweeps at 0.25, 1, and 4 V/s, with state and time columns | `memtransistor_model.json` |
| `neuristor_spikes_*.csv` | Node voltage versus time with spike state, drive bias, and spike period at 2, 3.5, and 5 V supply | `neuristor_model.json` |

`memristor_stack.stl` and `memtransistor_stack.stl` are schematic CAD drawings
in millimetres. Layer heights are enlarged for visibility; use the paired JSON
to load the electrical parameters. In the 3D tab, load the STL and answer
**Yes** to loading its JSON model. The imported family and parameters are then
available to the memory-characteristic generator. Alternatively, select the
device family directly in the main UI and load the CSV files using **Import
curves**.

After loading the matching traces, **Calculate all curves** extracts the
resistance window, on/off ratio, current range, memory-state swing, and I-V or
Id-Vg hysteresis-loop area. The values describe these generated curves only.
For the neuristor traces the same button reports the spike count, peak and rest
voltage, inter-spike period, firing rate, and period jitter.

The neuristor model switches at `V_t = 1.2 V` with `R_cold = 20 kΩ` and
`R_load = 5 kΩ`, so the drive must exceed the critical supply
`V_t·(R_cold + R_load)/R_cold = 1.5 V` before any spike appears. The bundled
traces use 2, 3.5, and 5 V, all above that level, and the firing rate rises with
the supply.

Select **Export Verilog-A** to generate a parameterized `.va` behavioral model.
The memristor terminals are `(p, n)`; the memtransistor terminals are `(d, g, s)`.
The neuristor is a two-terminal `(p, n)` segment that switches on `V_t`, releases
below `V_h`, and holds off for `t_ref`, emitting a `$strobe` per spike.
The generated source embeds Ron/Roff, SET/RESET thresholds, ionic mobility,
active-layer thickness, activation energy, initial state, and (for the
memtransistor) gate coupling and retention time. The 300 K nominal reference is
used for activation-energy scaling. These are illustrative behavioral models,
not calibrated compact models; compile and validate the generated file with
the target simulator because Verilog-A support and accepted analog operators
differ among simulators.

The **3D / Тепло / Поле** tab also renders separate 3D stacks for both devices:
Si / SiO₂ / TiN / switching oxide / top electrode for the memristor, and a
bottom-gated substrate / SiO₂ / channel / source-drain contacts / top-gate
dielectric and metal for the memtransistor. **Рассчитать тепло и поле** runs
the application's tetrahedral thermal, electrostatic, and magnetic-field
paths for these families. The electrostatic FEM assigns separate permittivity
values to the silicon, SiO₂, active channel, and nominal Al₂O₃ gate dielectric.
As with the other device families, this remains a reduced model: thermal
conductivity is uniform, the electrostatic solve omits mobile charge and
state-dependent filament geometry, and the magnetic field is an analytical
Biot–Savart estimate, not a full Maxwell or coupled electrothermal simulation.
The carrier-charge Poisson–Schrödinger button is disabled for these devices
because the current quantum model does not support their material/state physics.

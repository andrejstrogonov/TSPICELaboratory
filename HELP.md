# Руководство пользователя: TSPICE Laboratory

**TSPICE Laboratory** — настольное приложение для анализа характеристик полупроводниковых приборов и элементов нейроморфной памяти, расчёта параметров компактных моделей, 3D-визуализации CAD-геометрии и экспорта файлов для схемотехнического моделирования (**SPICE BSIM4** и **Verilog-A**).

---

## 1. Обзор рабочего окна

Интерфейс разделён на две основные области:
1. **Левая панель управления:** выбор типа прибора, ввод параметров материала и геометрии, кнопки импорта/экспорта, список загруженных кривых и индикатор состояния видеокарты (GPU).
2. **Правая панель визуализации и отчётов:** интерактивный график (2D-характеристики или 3D-сетка CAD) с панелью масштабирования и текстовое окно с результатами расчётов.

---

## 2. Пошаговый порядок работы

### Сценарий А: Анализ измеренных или смоделированных характеристик (CSV)
1. **Выберите тип структуры** в выпадающем списке *«Структура»* (например, `Планарный MOSFET`, `FinFET`, `Мемристор`, `Мемтранзистор` или `Нейристор`). Форма ниже автоматически перестроится под параметры выбранного прибора.
2. **Задайте параметры материала и геометрии.** Укажите имя модели (без пробелов), диэлектрическую проницаемость, подвижности носителей, ширину запрещённой зоны, легирование, размеры и температуру (по умолчанию `300 К`).
3. **Загрузите данные.** Нажмите **«Импорт CSV»** и выберите один или несколько файлов. Загруженные кривые появятся в списке *«Загруженные характеристики»* с меткой распознанного типа (например, `[IDVG]`, `[MEMRISTOR_IV]`, `[NEURISTOR_SPIKES]`).
4. **Выполните расчёт.** Выделите нужную кривую в списке и нажмите **«Рассчитать параметры»**. Извлечённые метрики отобразятся в нижнем текстовом поле справа.
5. **Сохраните результат.** Нажмите кнопку экспорта в нижней части панели:
   * для `Планарный MOSFET` — **«Экспорт BSIM4-модели»** (`.model`);
   * для `Мемристор`, `Мемтранзистор` и `Нейристор` — **«Экспорт Verilog-A модели»** (`.va`);
   * для остальных транзисторов (`FinFET`, `GAA`, `FD-SOI`, `TFET`, `HEMT`) — **«Экспорт JSON-отчёта»** (`.json`).

### Сценарий Б: Поведенческое моделирование элементов памяти и генерация Verilog-A

Для **мемристоров**, **мемтранзисторов** и **нейристоров** программа умеет сама рассчитывать типовые кривые без загрузки внешнего CSV:
1. Выберите `Мемристор`, `Мемтранзистор` или `Нейристор`.
2. Заполните параметры активного слоя (сопротивления `R_on`/`R_off`, пороги `SET`/`RESET`, подвижность ионов, энергию активации и др.).
3. Задайте границы развёртки (`V min`, `V max` для мемристора или `Vd` для мемтранзистора) и нажмите **«Рассчитать кривые памяти»**. Программа сгенерирует семейство кривых для разных скоростей развёртки (или напряжений питания для нейристора) и добавит их в список.
4. Для мемристора выберите в поле *«Метод Verilog-A»* нужную математическую модель (`Дрейф ионов (общий)` или `Sol-gel оксид (пороговый)`) и нажмите **«Экспорт Verilog-A модели»**. *(Примечание: экспортировать `.va`-файл можно сразу после ввода параметров, даже без предварительного построения кривых.)*

#### Шаг 5. Подключение сгенерированной Verilog-A модели (`.va`) в САПР

Сгенерированный файл содержит стандартные директивы `` `include "constants.vams" ``, `` `include "disciplines.vams" `` и описание модуля с выводами `(p, n)` для двухполюсников (мемристор, нейристор) или `(d, g, s)` для трёхполюсников (мемтранзистор).

##### Вариант 1: Cadence Virtuoso (Spectre / AMS) — создание символа в библиотеке
Этот способ позволяет использовать прибор как полноценный библиотечный элемент на принципиальной схеме:
1. **Создайте ячейку:** в окне **Library Manager** выберите вашу рабочую библиотеку и нажмите **File -> New -> Cell View...**
2. **Укажите тип представления:**
   * В поле **Cell** введите имя модуля (должно совпадать с именем после ключевого слова `module` в `.va`-файле, например `custom_nmos` или `memristor_test`).
   * В поле **View** напишите `veriloga`.
   * В выпадающем списке **Type** выберите **VerilogA** и нажмите **OK**.
3. **Вставьте код:** в открывшемся текстовом редакторе полностью замените шаблонный текст содержимым сохранённого `.va`-файла из `TSPICELaboratory` и нажмите **File -> Save** (или иконку дискеты).
4. **Скомпилируйте и создайте символ:**
   * Закройте редактор. Virtuoso автоматически запустит проверку синтаксиса (`ahdlcmi` / Spectre parser) и выведет результат в окно **CIW** (основное окно Virtuoso).
   * На вопрос *«Do you want to create a symbol for this cellview?»* нажмите **Yes** (если окно не появилось, нажмите правой кнопкой мыши на вид `veriloga` -> **Create Cellview -> From Cellview...**).
   * В окне генерации символа проверьте раскладку выводов (`p` и `n` — слева/справа или сверху/снизу; для мемтранзистора `d`, `g`, `s`) и нажмите **OK**.
5. **Подключите в схему и запустите расчёт:**
   * Разместите созданный символ на схеме (**Create -> Instance**).
   * Запустите **ADE L** (или **ADE Explorer**), выберите симулятор **Spectre**.
   * Настройте анализ **Transient (`tran`)** — для мемристоров и нейристоров обязателен временной анализ (поскольку изменение состояния описывается интегралом `idt(dxdt, x_init)`). При необходимости во вкладке **Simulation -> Options -> Analog** установите `reltol = 1e-4` или `1e-5` для более плавного прохождения порогов `Vset` / `Vreset`.

##### Вариант 2: Быстрое подключение в Cadence ADE без создания символа (через Netlist / Model Files)
Если схема уже собрана на базе идеального элемента или подцепи:
1. Откройте **ADE L / ADE Explorer**.
2. Перейдите в меню **Setup -> Model Libraries...** (или **Simulation Files -> Definition Files**).
3. Добавьте путь к сохранённому файлу `<имя_модели>.va` и поставьте галочку активации.
4. В SPICE-нетлисте (или через `ahdl_include "/путь/к/файлу.va"`) вызывайте экземпляр как обычный элемент:
   * для мемристора / нейристора: `Xmem1 net_top net_bot <имя_модуля> Ron=100 Roff=100k`
   * для мемтранзистора: `Xmtrans1 drain gate source <имя_модуля>`

##### Вариант 3: Открытые SPICE-симуляторы (Ngspice, Qucs-S, Xyce)
* **Ngspice (версии 39+) и Qucs-S:**
  1. Скомпилируйте `.va`-файл в библиотеку формата **OSDI** с помощью утилиты **OpenVAF** (`openvaf model.va`).
  2. В схеме или `.cir`-файле подключите скомпилированную библиотеку командой `.osdi model.osdi` и задайте модель `.model my_mem <имя_модуля>`.
  3. Для максимальной совместимости с OpenVAF при экспорте мемристора из `TSPICELaboratory` рекомендуется выбирать метод **«Sol-gel оксид (пороговый)»**, так как он не использует функцию `limexp()`.
* **Xyce (Sandia National Laboratories):**
  * Поддерживает трансляцию Verilog-A в C++ через встроенный компилятор `buildxyceplugin` (`buildxyceplugin model.va ./plugin_dir`), после чего подключается флагом `-plugin` при запуске расчёта.

### Сценарий В: Работа с 3D-геометрией (CAD STL)

Программа поддерживает импорт трёхмерных поверхностных сеток в формате **STL** (бинарном и текстовом ASCII, до **2 000 000 треугольников**). Обязательное требование: модель должна быть объёмной и иметь ненулевой размер по всем трём осям (`X`, `Y`, `Z`) — плоские 2D-контуры не принимаются.

#### Шаг 1. Подготовка и экспорт STL из сторонних САПР и TCAD

Перед сохранением файла убедитесь, что запомнили единицы измерения проекта, так как сам формат `.stl` не хранит информацию о масштабе.

* **COMSOL Multiphysics:**
  * *Из геометрии:* в дереве модели перейдите в `Component -> Geometry`, нажмите правой кнопкой мыши и выберите **Export** (или вкладка `Geometry -> Export`). В поле *File type* укажите **STL binary file (*.stl)** (рекомендуется для скорости) или **STL text file (*.stl)**. Единицы измерения соответствуют настройке `Length unit` в узле `Geometry` (обычно `nm`, `µm` или `mm`).
  * *Из расчётной сетки:* перейдите в `Component -> Mesh`, нажмите правой кнопкой мыши -> **Export**, выберите формат **STL (*.stl)**.
* **ANSYS (SpaceClaim / Discovery / Mechanical):**
  * *SpaceClaim / Discovery:* выберите меню **Файл -> Сохранить как** (`File -> Save As`), в типе файла укажите **STL (*.stl)**. В окне **Параметры** (`Options`) проверьте единицы измерения (`мм` или `мкм`) и задайте умеренную точность фасетизации, чтобы число треугольников не превышало 2 млн.
  * *ANSYS Mechanical (из готовой сетки):* нажмите правой кнопкой мыши на **Model** или **Mesh** в дереве проекта -> **Export -> STL File**.
* **КОМПАС-3D:**
  * Откройте 3D-деталь или сборку (`.m3d` / `.a3d`).
  * Перейдите в меню **Файл -> Сохранить как...** и выберите тип файла **STL (*.stl)**.
  * Нажмите кнопку **Параметры** в диалоге сохранения: выберите формат **Двоичный** (бинарный) и укажите единицы измерения (**Миллиметры** или **Микрометры**). *Совет: при построении нанометровых слоёв в КОМПАС-3D не используйте мелкие фаски и скругления — они многократно увеличивают число треугольников сетки.*
* **SolidWorks / Autodesk Inventor / FreeCAD:**
  * *SolidWorks:* **Файл -> Сохранить как** -> тип **STL (*.stl)** -> кнопка **Параметры** -> выберите двоичный формат, единицы измерения и снимите галочку *«Не переносить данные STL в положительное пространство»* при необходимости сохранения исходных координат.
  * *FreeCAD:* выделите нужное тело в дереве проекта -> **Файл -> Экспортировать** (`Ctrl+E`) -> выберите **STL Mesh (*.stl, *.ast)**.

#### Шаг 2. Загрузка и настройка в TSPICE Laboratory

1. В левой панели программы нажмите **«Загрузить CAD STL»** и выберите подготовленный файл `.stl`.
2. В появившемся диалоговом окне **«Единицы STL»** укажите те единицы, в которых была экспортирована модель (`мм`, `мкм`, `м` или `дюймы`). Программа автоматически пересчитает координаты всех вершин в **нанометры (нм)**. *(Если модель в COMSOL строилась сразу в нанометрах, перед экспортом переключите `Length unit` на `µm`, чтобы выбрать `мкм` при импорте.)*
3. На запрос **«Параметры CAD-устройства»**:
   * Нажмите **«Да»**, если у вас есть ранее сохранённый `.json`-отчёт из программы — семейство прибора, свойства материала и геометрии подгрузятся автоматически.
   * Нажмите **«Нет»**, чтобы оставить текущую структуру или заполнить физические параметры активного слоя вручную.
4. **Просмотр и очистка:** трёхмерная модель появится в правом окне графика (доступно вращение и масштабирование мышью; сетки свыше 40 000 граней автоматически прореживаются для плавной отрисовки). Чтобы удалить модель со сцены и вернуться в обычный режим, нажмите **«Сбросить CAD»**.

## 3. Требования к входным CSV-файлам и способы их экспорта

* **Разделители:** запятая (`,`), точка с запятой (`;`) или табуляция (`\t`).
* **Заголовки:** обязательны в первой строке. Пробелы, регистр и единицы измерения в скобках (например, `Vg (V)`, `Id [A]`) распознаются и отбрасываются автоматически. *Важно: не оставляйте строки комментариев начинающиеся с `#` или `%` перед строкой заголовка — первая строка файла должна содержать имена столбцов.*
* **Единицы измерения:** строго система СИ — Вольты (`В`), Амперы (`А`), Фарады (`Ф`), Омы (`Ом`), Секунды (`с`).

### Откуда и как выгрузить CSV-характеристики

#### 1. COMSOL Multiphysics (TCAD / Semiconductor / AC/DC)
Для получения интегральных кривых (ВАХ, \(C–V\), динамика переключения) используется раздел результатов:
1. **Вычисление интегральных величин:** перейдите в `Results -> Derived Values` -> **Global Evaluation** (или **Surface Integration** по поверхности контакта). Выведите в таблицу (`Table`) напряжение на контакте, полный ток через электрод и усреднённую переменную состояния (например, долю вакансий или длину филамента в интервале ``).
2. **Добавление расчётных столбцов (при необходимости):** для ВАХ мемристора добавьте в таблицу столбец сопротивления (`R = V / I`), так как парсер требует его наличия в явном виде.
3. **Экспорт таблицы:**
   * На панели инструментов окна `Table` нажмите кнопку **Export** (иконка сохранения) или перейдите в `Results -> Export -> Table`.
   * В поле *File type* выберите **CSV files (*.csv)** (или `.txt` с разделителем табуляция/точка с запятой).
   * Убедитесь, что в настройках экспорта включена выгрузка заголовков столбцов (`Include header`), и удалите служебные строки с метаданными COMSOL в начале файла (если они добавились при экспорте из `Plot`), оставив первой строкой названия столбцов.

#### 2. Silvaco TCAD (Atlas / Victory Device / TonyPlot)
1. После завершения расчёта откройте выходной `.log`-файл в программе **TonyPlot**.
2. Выберите нужные оси (например, `Gate Voltage` по оси X и `Drain Current` по оси Y) для построения \(I_d–V_g\), \(I_d–V_d\) или \(C–V\).
3. В верхнем меню TonyPlot выберите **File -> Export...**.
4. В окне экспорта выберите формат **CSV (Comma Separated Values)** или **Spreadsheet**.
5. Откройте полученный файл в текстовом редакторе или Excel, переименуйте длинные системные имена Silvaco (например, `Gate Voltage (V)` -> `Vg`, `Drain Current (A)` -> `Id`) и при необходимости возьмите модуль тока (`abs(Id)`), так как программа отклоняет отрицательные токи транзисторов.

#### 3. ANSYS (Lumerical CHARGE / ANSYS Electronics Desktop)
* **ANSYS Lumerical CHARGE:**
  1. В дереве объектов откройте результаты расчёта монитора заряда/контакта (`charge -> results`).
  2. Выберите нужный датасет (`I` или `C`), нажмите правой кнопкой мыши и выберите **Export to -> CSV / Text** (либо выгрузите через скрипт командой `write("iv_curve.csv", ...)`).
* **ANSYS Electronics Desktop (Maxwell / Twin Builder):**
  1. Откройте построенный график в разделе **Results**.
  2. Нажмите правой кнопкой мыши на поле графика -> **Export...** -> выберите тип файла **Comma Separated Value Files (*.csv)**.

#### 4. Измерительные стенды (Keysight B1500A / Keithley 4200-SCS) и Excel
* **Характериографы (EasyEXPERT / Clarius):** выполните экспорт листа данных (Sheet) в формате **CSV**. Удалите верхнюю шапку с параметрами прибора и датой измерения так, чтобы самой первой строкой файла шли заголовки столбцов (`Vg`, `Id`, `Vd` и т.д.).
* **Подготовка в Excel / Python:** если кривая собиралась вручную или из осциллографа, сохраните таблицу через **Файл -> Сохранить как -> CSV (разделители — запятые) (*.csv)**. Проследите, чтобы дробные числа записывались через точку (например, `1.5e-6`), а не через запятую.

### Таблица обязательных столбцов для распознавания парсером

| Тип прибора / кривой | Обязательные столбцы | Дополнительные столбцы | Примечания |
| :--- | :--- | :--- | :--- |
| **Транзистор \(I_d–V_g\)** | `Vg` (или `Vgs`), `Id` (или `Ids`) | `Vd` (по умолч. `0.05 В`) | Минимум 5 точек; ток \(\ge 0\). |
| **Транзистор \(I_d–V_d\)** | `Vd` (или `Vds`), `Id` (или `Ids`) | `Vg` (постоянный bias) | Минимум 3 точки; ток \(\ge 0\). |
| **Транзистор \(C–V\)** | `Vg`, `Cg` (или `capacitance`) | — | Минимум 3 точки. |
| **Мемристор \(I–V\)** | `voltage` (`v`), `current` (`i`), `resistance` (`r`), `state` (`x`) | `time` (`t`), `sweep_rate` | Значения `state` строго в диапазоне ``. |
| **Мемристор \(R–t\)** | `time` (`t`), `resistance` (`r`), `state` (`x`) | `voltage` (`v`), `sweep_rate` | Определяет динамику сопротивления. |
| **Мемтранзистор \(I_d–V_g\)** | `vg` (`vgs`), `id` (`ids`), `state` (`x`) | `vd` (`vds`), `time` (`t`) | Значения `state` строго в диапазоне ``. |
| **Нейристор \(V(t)\)** | `time` (`t`), `state` (`x`), `supply_voltage` (`vdd`) или `spike_period` | `voltage` (`v`), `current` (`i`), `resistance` (`r`) | Фиксирует частоту и период генерации спайков. |

| **Нейристор \(V(t)\)** | `time` (`t`), `state` (`x`), `supply_voltage` (`vdd`) или `spike_period` | `voltage` (`v`), `current` (`i`), `resistance` (`r`) | Фиксирует частоту и период генерации спайков. |

## 4. Частые ошибки и их решение

* **«Unsupported CSV columns» при загрузке кривой мемристора.**
  * *Причина:* в файле отсутствует столбец внутреннего состояния (`state`, `memory_state` или `x`). Без него программа считает файл обычной транзисторной ВАХ.
* **«Memristor I-V data requires a resistance column».**
  * *Причина:* для расчёта метрик гистерезиса мемристора (`R_on`, `R_off`, отношение сопротивлений) в CSV-файле рядом с напряжением и током должен присутствовать столбец `resistance` (или `r`).
* **«Drain current values must be non-negative».**
  * *Причина:* в транзисторной характеристике присутствуют отрицательные значения тока (например, шум в подпороговой области). Очистите или обнулите отрицательные токи перед загрузкой.
* **«STL geometry must have non-zero extent along all axes».**
  * *Причина:* загружена плоская 2D-поверхность без толщины по одной из координат. Программа принимает только объёмные 3D-тела (до 2 000 000 треугольников).
* **Ошибка валидации параметров при нажатии «Рассчитать» или «Экспорт».**
  * Проверьте физическую корректность введённых границ:
    * Имя модели не должно содержать пробелов.
    * Для мемристора: `R_on < R_off`, `Порог SET > 0`, `Порог RESET < 0`, `0 <= x₀ <= 1`.
    * Для нейристора: `R горячего < R холодного`, `0 < V_h < V_t`, `Рефрактерное время > Тепловая постоянная`.
    * Для FinFET / GAA: шаг ребер/листов (`pitch`) не может быть меньше их ширины/толщины.

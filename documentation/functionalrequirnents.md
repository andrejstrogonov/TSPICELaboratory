# Функциональные требования (Functional Requirements Document)

## 1. Введение и Назначение системы
Настоящий документ определяет перечень функциональных и технических требований к программно-моделирующему комплексу на базе PyQt. Приложение предназначено для проведения физико-технологического моделирования полупроводниковых структур и автоматизированной экстракции карт SPICE-параметров по стандарту BSIM4 с использованием аппаратного ускорения NVIDIA CUDA.

## 2. Требования к оборудованию и Системному окружению
*   **Операционная система:** Microsoft Windows 10/11 (64-bit) или Linux (Ubuntu 22.04 LTS / Rocky Linux 9).
*   **Вычислительная платформа:** Наличие дискретного графического ускорителя NVIDIA (архитектура Ampere/Ada Lovelace, целевой GPU — **NVIDIA GeForce RTX 4090**).
*   **Программные слои:** Наличие установленных драйверов NVIDIA с поддержкой CUDA версии не ниже 12.0.
*   **Формат поставки:** Автономный исполняемый файл (`.exe` для Windows) со встроенными динамическими библиотеками вычислений.

## 3. Функциональные требования к модулям ПО

### Модуль 3.1. Графический интерфейс пользователя (GUI на PyQt)
*   **FR-1.1:** Предоставление интерактивной формы для ввода фундаментальных физических констант материала: диэлектрической проницаемости ($\varepsilon$), подвижности носителей заряда ($\mu_n$, $\mu_p$), ширины запрещенной зоны ($E_g$), потенциалов ионизации и параметров легирования.
*   **FR-1.2:** Наличие встроенного интерактивного окна для визуализации результатов (семейства ВАХ и ВФХ) на базе библиотеки `matplotlib` с возможностью экспорта графиков в форматы PNG/PDF.
*   **FR-1.3:** Индикация состояния графического процессора (GPU) в реальном времени: загрузка ядер, использование видеопамяти (VRAM), текущая температура (интеграция через утилиту `nvidia-smi` или API PyTorch).

### Модуль 3.2. Физико-технологическое TCAD-ядро (DEVSIM + CUDA)
*   **FR-2.1:** Формирование 1D/2D/3D пространственной сетки (Mesh) транзисторной структуры или программируемого вентиля (LUT ПЛИС) на основе введенных геометрических параметров техпроцесса (базовый шаг — до 55/28 нм).
*   **FR-2.2:** Аппаратно-ускоренное решение систем дифференциальных уравнений в частных производных (уравнения Пуассона, уравнения непрерывности для электронов и дырок) с использованием тензорных ядер GPU через бэкенды PyTorch/JAX.
*   **FR-2.3:** Генерация числовых массивов данных статических вольт-амперных характеристик (сток-затворные $I_d(V_g)$, стоковые $I_d(V_d)$) и вольт-фарадных характеристик (емкости затвора $C_g(V_g)$).

### Модуль 3.3. Экстрактор SPICE-параметров (SciPy/NumPy)
*   **FR-3.1:** Автоматический импорт сгенерированных массивов ВАХ/ВФХ во внутренний оптимизатор.
*   **FR-3.2:** Математический фиттинг (аппроксимация) полученных кривых под уравнения промышленного стандарта **BSIM4** с использованием алгоритмов нелинейного метода наименьших квадратов (`scipy.optimize.least_squares`).
*   **FR-3.3:** Экстракция ключевых макропараметров: порогового напряжения ($V_{th}$), фактора подпороговой крутизны, паразитных емкостей переходов и эффективной подвижности носителей в канале.

### Модуль 3.4. Экспорт данных и Интеграция с EDA
*   **FR-4.1:** Формирование текстового файла технологической карты параметров модели в синтаксисе стандартного SPICE (`.model` / `.subckt`).
*   **FR-4.2:** Обеспечение 100% синтаксической совместимости выходного файла с симуляторами **Tanner T-Spice** (Siemens EDA) и **Ngspice**.
*   **FR-4.3:** Выгрузка обобщенных векторов задержек переключения для последующего масштабирования временных файлов задержек (SDF) в среде **AMD/Xilinx Vivado**.

## 4. Нефункциональные требования и Ограничения
*   **Производительность:** Расчет базовой 2D-сетки транзистора при развертывании вычислений на GPU NVIDIA RTX 4090 не должен превышать 30 секунд (выигрыш по времени относительно однопоточных CPU-решений — не менее 10х).
*   **Стабильность и Отказоустойчивость:** Приложение должно перехватывать ошибки переполнения памяти GPU (CUDA Out of Memory) и корректно высвобождать кэш VRAM без аварийного завершения основного GUI-процесса.
*   **Переносимость (Portability):** Сборка приложения должна включать в себя все необходимые CUDA-рантаймы (`cudart64_*.dll`), исключая необходимость предварительной установки NVIDIA CUDA Toolkit пользователем.

## 5. Статус реализации

Текущая версия проекта реализует формы параметров для planar bulk MOSFET, FD-SOI, FinFET, GAA nanosheet, GAA nanowire, TFET и HEMT. Для структурных типов UI предоставляет поля толщины тела/BOX/back-gate, размеров и числа fin, листов или nanowire, туннельной области и легирования TFET, а также материала/толщины барьера, плотности 2DEG, подвижности канала и сопротивления доступа HEMT. Для FinFET/GAA рассчитывается эффективный периметр канала.

Вкладка 3D показывает геометрическую схему выбранного типа устройства и позволяет вращать сцену; изменения геометрических полей отображаются в схеме. Стационарная тепловая задача решается линейным тетраэдральным методом конечных элементов для однородной теплопроводности `k`: мощность канала принимается `Vds * Id`, источник распределяется вблизи канала, температура внешних граней фиксируется на температуре окружающей среды. Выводятся карта температуры, `Tmax`, `ΔT` и `Rth`. Разреженная FEM-система решается через CUDA/PyTorch sparse conjugate gradient при доступной CUDA-сборке; иначе применяется SciPy CPU direct solver. Применённый backend отображается в UI.

Структурированная тетраэдральная сетка локально сгущается вблизи геометрически заданных положений затвора, канала и границ слоёв. CUDA CG выполняется в FP64; перед переносом разреженной матрицы оценивается потребность в VRAM, при недостатке доступной памяти выбирается CPU solver. Это геометрически управляемое сгущение, не итерационный алгоритм адаптации по апостериорной оценке FEM-ошибки; отдельные профили точности для RTX 4070 Ti SUPER и RTX 4090 не заявляются.

Интерфейс импортирует бинарные и текстовые STL из AutoCAD/КОМПАС-3D с выбором единиц и добавляет структуру в список как пользовательский CAD-транзистор. Параметры можно заполнить в форме либо загрузить JSON-отчёт параметров приложения; выбранный тип модели используется анализом CSV и существующими решателями. FEM-поле отображается цветом на CAD-поверхности после переноса по габаритам, но сама STL-поверхность пока не преобразуется в объёмную сетку и не включается в FEM-матрицу. Пример STL находится в `data/examples/example_transistor_channel.stl`.

Электрическая задача — квазистатическое 3D FEM-решение уравнения Лапласа на линейных тетраэдрах: контакты source/drain и gate являются границами Дирихле, остальные границы имеют нулевой нормальный градиент. Выводятся карта модуля электрического поля, оценка геометрической ёмкости и энергии. Отдельно показывается аналитическая карта магнитной индукции Biot–Savart для прямого конечного проводника по заданному току стока. Это не полный расчёт уравнений Максвелла: свободные/подвижные заряды, неоднородная диэлектрическая проницаемость, волновые и переходные эффекты не моделируются. Сетка и материал упрощены; FEM-результат предназначен для инженерной оценки, а не для проектной верификации.

Тепловые, электрические и магнитные скалярные поля накладываются цветом на поверхность структуры. При наведении интерфейс показывает координаты и интерполированное значение поля. Для CAD-геометрии перенос по габаритам служит только визуализации: решатель не использует STL как физическую расчётную область. Электрический solver не включает уравнение Пуассона с подвижными носителями или связанный дрейф-диффузионный расчёт.

Приложение импортирует и визуализирует CSV-характеристики Id–Vg, Id–Vd и C–V. Id–Vg MOS-семейств аппроксимируется упрощённой аналитической зависимостью; для TFET/HEMT вычисляются curve metrics (`VTH_CONSTANT_CURRENT`, `ION`, `IOFF`, `ION/IOFF`, SS, `gm`), а для Id–Vd — `RON`, `gds` и токовые метрики. C–V даёт упрощённую оценку ёмкостей. BSIM4 `.model` экспортируется только для planar bulk MOSFET; остальные семейства экспортируют JSON-отчёт, а не неподходящую им BSIM4-карту. CSV использует напряжение в вольтах, ток в амперах и ёмкость в фарадах. Синтетические наборы для всех перечисленных семейств находятся в `data/examples/`.

Решение уравнений Пуассона и непрерывности для полупроводника, создание TCAD-сетки из CAD-поверхности, вычисление характеристик в DEVSIM/CUDA, полный Maxwell/FEM solver, прямой импорт результатов DEVSIM, полная калибровка моделей FinFET/GAA/TFET/HEMT, генерация SDF и сборка PyInstaller пока не реализованы. Отображение GPU использует `nvidia-smi` только для диагностики и не означает, что вычисления ускоряются на GPU. Геометрические поправки и оценки ёмкостей являются приближениями, а не полноценным TCAD/compact-model extraction flow.

# Функциональные требования (Functional Requirements Document)

## 1. Введение и Назначение системы
Настоящий документ определяет перечень функциональных и технических требований к программно-моделирующему комплексу на базе PyQt. Приложение предназначено для проведения физико-технологического моделирования полупроводниковых структур и автоматизированной экстракции карт SPICE-параметров по стандарту BSIM4 с использованием аппаратного ускорения NVIDIA CUDA.

## 2. Требования к оборудованию и Системному окружению
*   **Операционная система:** Microsoft Windows 10/11 (64-bit) или Linux (Ubuntu 22.04 LTS / Rocky Linux 9).
*   **Вычислительная платформа:** Наличие дискретного графического ускорителя NVIDIA (архитектура Ampere/Ada Lovelace, целевой GPU — **NVIDIA GeForce RTX 4090**).
*   **Программные слои:** Наличие установленных драйверов NVIDIA с поддержкой CUDA версии не ниже 12.0.
*   **Формат поставки:** Автономный исполняемый файл (`.exe` для Windows) со встроенными динамическими библиотеками вычислений.

## 3. Функциональные требования к модулям ПО

### Модуль 3.1. Графический интерфейс пользователя (GUI на PyQt)
*   **FR-1.1:** Предоставление интерактивной формы для ввода фундаментальных физических констант материала: диэлектрической проницаемости ($\varepsilon$), подвижности носителей заряда ($\mu_n$, $\mu_p$), ширины запрещенной зоны ($E_g$), потенциалов ионизации и параметров легирования.
*   **FR-1.2:** Наличие встроенного интерактивного окна для визуализации результатов (семейства ВАХ и ВФХ) на базе библиотеки `matplotlib` с возможностью экспорта графиков в форматы PNG/PDF.
*   **FR-1.3:** Индикация состояния графического процессора (GPU) в реальном времени: загрузка ядер, использование видеопамяти (VRAM), текущая температура (интеграция через утилиту `nvidia-smi` или API PyTorch).

### Модуль 3.2. Физико-технологическое TCAD-ядро (DEVSIM + CUDA)
*   **FR-2.1:** Формирование 1D/2D/3D пространственной сетки (Mesh) транзисторной структуры или программируемого вентиля (LUT ПЛИС) на основе введенных геометрических параметров техпроцесса (базовый шаг — до 55/28 нм).
*   **FR-2.2:** Аппаратно-ускоренное решение систем дифференциальных уравнений в частных производных (уравнения Пуассона, уравнения непрерывности для электронов и дырок) с использованием тензорных ядер GPU через бэкенды PyTorch/JAX.
*   **FR-2.3:** Генерация числовых массивов данных статических вольт-амперных характеристик (сток-затворные $I_d(V_g)$, стоковые $I_d(V_d)$) и вольт-фарадных характеристик (емкости затвора $C_g(V_g)$).

### Модуль 3.3. Экстрактор SPICE-параметров (SciPy/NumPy)
*   **FR-3.1:** Автоматический импорт сгенерированных массивов ВАХ/ВФХ во внутренний оптимизатор.
*   **FR-3.2:** Математический фиттинг (аппроксимация) полученных кривых под уравнения промышленного стандарта **BSIM4** с использованием алгоритмов нелинейного метода наименьших квадратов (`scipy.optimize.least_squares`).
*   **FR-3.3:** Экстракция ключевых макропараметров: порогового напряжения ($V_{th}$), фактора подпороговой крутизны, паразитных емкостей переходов и эффективной подвижности носителей в канале.

### Модуль 3.4. Экспорт данных и Интеграция с EDA
*   **FR-4.1:** Формирование текстового файла технологической карты параметров модели в синтаксисе стандартного SPICE (`.model` / `.subckt`).
*   **FR-4.2:** Обеспечение 100% синтаксической совместимости выходного файла с симуляторами **Tanner T-Spice** (Siemens EDA) и **Ngspice**.
*   **FR-4.3:** Выгрузка обобщенных векторов задержек переключения для последующего масштабирования временных файлов задержек (SDF) в среде **AMD/Xilinx Vivado**.

## 4. Нефункциональные требования и Ограничения
*   **Производительность:** Расчет базовой 2D-сетки транзистора при развертывании вычислений на GPU NVIDIA RTX 4090 не должен превышать 30 секунд (выигрыш по времени относительно однопоточных CPU-решений — не менее 10х).
*   **Стабильность и Отказоустойчивость:** Приложение должно перехватывать ошибки переполнения памяти GPU (CUDA Out of Memory) и корректно высвобождать кэш VRAM без аварийного завершения основного GUI-процесса.
*   **Переносимость (Portability):** Сборка приложения должна включать в себя все необходимые CUDA-рантаймы (`cudart64_*.dll`), исключая необходимость предварительной установки NVIDIA CUDA Toolkit пользователем.

# TSPICE Laboratory

Настольное приложение на **Python / PyQt6** для анализа вольт-амперных, вольт-фарадных и динамических характеристик полупроводниковых приборов и элементов памяти, экстракции параметров компактных моделей, поведенческого моделирования и экспорта карт **SPICE (BSIM4)** и **Verilog-A**.

---

## Поддерживаемые классы приборов

### 1. Транзисторные структуры (`planar_mosfet`, `fd_soi`, `finfet`, `gaa_nanosheet`, `gaa_nanowire`, `tfet`, `hemt`)
* **MOS-структуры (`planar_mosfet`, `fd_soi`, `finfet`, `gaa_nanosheet`, `gaa_nanowire`):** аппроксимация передаточных характеристик \(I_d–V_g\) методом нелинейных наименьших квадратов (`scipy.optimize.least_squares`) в логарифмическом масштабе для извлечения \(V_{TH0}\), \(U_0\) и \(NFACTOR\). Для `FinFET`, `GAA nanosheet` и `GAA nanowire` автоматически рассчитывается эффективный проводящий периметр канала.
* **TFET и HEMT:** прямой расчёт метрик по кривой без аппроксимации BSIM4 — пороговое напряжение по постоянному току (`VTH_CONSTANT_CURRENT`), \(I_{ON}\), \(I_{OFF}\), отношение \(I_{ON}/I_{OFF}\), минимальный подпороговый наклон (`SS_MV_DEC`) и максимальная крутизна (`GM_MAX`). Для `HEMT` дополнительно рассчитываются слоевое сопротивление (`RSH_OHM_SQ`) и сопротивление доступа (`RACCESS_OHM`).
* **Выходные и емкостные характеристики:** оценка максимального тока (`IDS_MAX`), сопротивления открытого канала (`RON_OHM`) и выходной проводимости (`GDS_S`) по кривым \(I_d–V_d\), а также расчёт полной ёмкости затвора (`CGG`) и перекрывающих ёмкостей (`CGSO`, `CGDO`) по \(C–V\).

### 2. Элементы памяти и нейроморфные приборы (`memristor`, `memtransistor`, `neuristor`)
* **Мемристор (`memristor`):** двухвыводная модель переключения проводящего филамента с внутренним состоянием \(x \in [0, 1]\), порогами `SET`/`RESET`, температурной зависимостью ионной подвижности (закон Аррениуса) и оконной функцией. Поддерживает генерацию гистерезисных кривых \(I–V\) и временных зависимостей \(R(t)\) для трёх скоростей развёртки (`10`, `100`, `1000 В/с`).
* **Мемтранзистор (`memtransistor`):** трёхвыводная модель (`D`, `G`, `S`), где затвор модулирует проводимость канала и скорость изменения состояния с учётом времени релаксации памяти (`tau_ret`) и коэффициента связи (`gate_coupling`). Генерирует гистерезисные передаточные кривые \(I_d–V_g\) для скоростей развёртки `0.25`, `1.0` и `4.0 В/с`.
* **Нейристор (`neuristor`):** энергонезависимо не хранящий состояние пороговый переключатель на переходе металл–изолятор (Mott / \(\text{VO}_2\)) с гистерезисом \(V_t > V_h\), нагрузочным резистором, ёмкостью линии и рефрактерным периодом (`t_ref`). Симулирует генерацию спайков при превышении критического напряжения питания.

### 3. Импорт CAD-геометрии (`cad_custom`)
* Загрузка бинарных и ASCII **STL-моделей** (до 2 000 000 треугольников) с выбором исходных единиц измерения (`мм`, `мкм`, `м`, `дюймы`) и автоматическим пересчётом координат в нанометры.
* Интерактивная 3D-визуализация геометрии в окне графика (с автоматическим прореживанием сетки при числе граней более 40 000).
* Подгрузка параметров материала и геометрии из сопутствующего `.json`-отчёта или ручной ввод в форме.

## Экспорт моделей и отчётов

* **Verilog-A модели (`.va`):**
  * *Мемристор — метод «Дрейф ионов (общий)» (`drift`):* компактная модель с интегрированием состояния `idt(dxdt, x_init)`, степенной оконной функцией и температурной поправкой через `limexp()`.
  * *Мемристор — метод «Sol-gel оксид (пороговый)» (`sol_gel`):* консервативная пороговая модель дрейфа кислородных вакансий без использования `limexp()` для повышенной сходимости в схемотехнических САПР.
  * *Мемтранзистор:* трёхвыводной модуль `module <name>(d, g, s)` с релаксацией состояния и сдвигом порога.
  * *Нейристор:* пороговый модуль `module <name>(p, n)` с отслеживанием рефрактерного интервала через `$abstime` и выводом событий спайков через `$strobe`.
* **SPICE-модель (`.model`):** генерация карты `BSIM4` (`level=54 version=4.8.1`) с параметрами `VTH0`, `U0`, `NFACTOR`, `CGSO`, `CGDO`, `TOXE` (доступно только для `planar_mosfet`).
* **JSON-отчёт (`.json`):** полная сериализация параметров материала, геометрии и извлечённых метрик для всех остальных типов приборов.
* **Графики:** экспорт построенных 2D- и 3D-графиков в форматы **PNG** и **PDF**.

## Требования и установка

Требуется **Python 3.10** или новее (`PyQt6`, `matplotlib`, `numpy`, `scipy`).

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd TSPICELaboratory
   ```

2. Создайте и активируйте виртуальное окружение:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите приложение:
   ```bash
   python -m src.main
   ```

Для сборки автономного установщика под Windows используется сценарий **Inno Setup** (`installer.iss`) с точкой входа `launcher.py`.

## Запуск тестов

Модульные тесты покрывают парсеры CSV, экстракцию параметров транзисторов и элементов памяти, генерацию Verilog-A и работу GUI в режиме `offscreen`:

```bash
python -m unittest discover -s tests -v
```

## Формат входных CSV-файлов (включая экспорт из COMSOL)

* Файл должен содержать строку заголовка (единицы измерения в скобках, например `Vg (V)` или `Id [A]`, автоматически отбрасываются при разборе).
* Поддерживаемые разделители: запятая (`,`), точка с запятой (`;`) и табуляция (`\t`).
* Базовые единицы СИ: напряжение — **В**, ток — **А**, ёмкость — **Ф**, время — **с**, сопротивление — **Ом**.

### 1. Транзисторные характеристики

| Тип кривой | Обязательные столбцы | Опциональные столбцы | Мин. точек |
| :--- | :--- | :--- | :---: |
| **\(I_d–V_g\)** | `Vg` (или `Vgs`), `Id` (или `Ids`) | `Vd` (если не задан, принимается `0.05 В`) | 5 |
| **\(I_d–V_d\)** | `Vd` (или `Vds`), `Id` (или `Ids`) | `Vg` (если постоянен, фиксируется как `VGS_BIAS`) | 3 |
| **\(C–V\)** | `Vg`, `Cg` (или `Cgg`, `capacitance`) | — | 3 |

### 2. Характеристики памяти и нейристоров
Для распознавания кривой как элемента памяти CSV-файл **обязательно** должен содержать столбец внутреннего состояния (`memory_state`, `state` или `x`) со значениями в интервале `[0, 1]`.

| Тип кривой | Обязательные столбцы | Дополнительные столбцы |
| :--- | :--- | :--- |
| **Мемристор \(I–V\)** (`memristor_iv`) | `voltage` (`v`), `current` (`i`), `resistance` (`r`), `state` (`x`) | `time` (`t`), `sweep_rate` (`rate`) |
| **Мемристор \(R–t\)** (`memristor_resistance`) | `time` (`t`), `resistance` (`r`), `state` (`x`) | `voltage` (`v`), `sweep_rate` (`rate`) |
| **Мемтранзистор \(I_d–V_g\)** (`memory_idvg`) | `vg` (`vgs`), `id` (`ids`), `state` (`x`) | `vd` (`vds`), `time` (`t`), `sweep_rate` (`rate`) |
| **Нейристор \(V(t)\)** (`neuristor_spikes`) | `time` (`t`), `state` (`x`), а также `supply_voltage` (`vdd`) или `spike_period` (`period`) | `voltage` (`v`), `current` (`i`), `resistance` (`r`), `propagation_delay` (`delay`) |

Готовые примеры CSV-таблиц, STL-моделей и JSON-описаний находятся в каталогах `data/examples/` и `data/examples/memory/`.

## Текущие ограничения

* Все вычисления и поведенческое моделирование выполняются на CPU (индикация GPU через `nvidia-smi` носит диагностический характер).
* Экстракция параметров опирается на аналитические компактные зависимости и метрики кривых, а не на сеточный PDE-решатель уравнений Пуассона и непрерывности.
* В модуле мемристора нажимать кнопку «Экспорт Verilog-A модели» можно сразу после задания параметров в форме или загрузки JSON-модели без обязательного предварительного фиттинга по CSV.

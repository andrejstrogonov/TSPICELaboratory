# GPU-Accelerated Semiconductor Modeling & Parameter Extraction Suite

Программно-моделирующий комплекс на базе гетерогенных вычислительных сред (CUDA/GPU) для сквозного физико-технологического моделирования полупроводниковых структур из перспективных материалов и автоматической экстракции компактных SPICE-моделей (BSIM4).

Проект разработан для предиктивного анализа и технологического сопровождения разработки цифровых интегральных схем и ПЛИС (FPGA) на системном уровне печатных плат.

## 🚀 Архитектура и Workflow комплекса

Комплекс связывает нанотехнологический уровень полупроводников с системным EDA-уровнем (Tanner T-Spice, Ngspice, AMD/Xilinx Vivado, Cadence Sigrity):

1. **Физика прибора (GPU):** Численное решение уравнений Пуассона и непрерывности на CUDA-ядрах (NVIDIA RTX 4090) с использованием библиотек DEVSIM, PyTorch и JAX. Выход: вольт-амперные (ВАХ) и вольт-фарадные (ВФХ) характеристики.
2. **Экстракция параметров (CPU/GPU):** Математическая аппроксимация расчетных кривых методами нелинейной оптимизации (SciPy/NumPy). Выход: технологическая карта параметров SPICE (стандарт BSIM4).
3. **Логическая верификация:** Генерация задержек и файлов SDF для сквозного моделирования цифровых автоматов в Vivado и анализа целостности сигналов/питания плат в Sigrity.

## 🛠 Стек технологий

*   **Графический интерфейс (UI):** Python 3.10+ / PyQt6 (или PyQt5)
*   **Вычислительное ядро TCAD:** DEVSIM (Open-Source TCAD Engine)
*   **GPU-Ускорение (CUDA):** PyTorch (с поддержкой CUDA 12+), JAX, СUDA Toolkit
*   **Математический аппарат:** NumPy, SciPy (модуль `scipy.optimize`)
*   **Сборка в исполняемый файл:** PyInstaller

## 📦 Быстрый старт и Сборка

### Требования к оборудованию
*   **GPU:** NVIDIA GeForce RTX 30/40 серий (оптимизировано под RTX 4090) с поддержкой CUDA.
*   **Драйверы:** NVIDIA Display Drivers с поддержкой CUDA Toolkit 12.x+.

### Развертывание среды разработки
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd tcad-gpu-extractor
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/scripts/activate  # Для Windows: venv\Scripts\activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
   *Примечание: Убедитесь, что версия `torch` установлена с флагом поддержки CUDA (например, с официального репозитория PyTorch).*

### Сборка автономного .EXE приложения
Для сборки переносимого приложения без необходимости установки интерпретатора Python на целевой машине используется `PyInstaller`:
```bash
pyinstaller --noconfirm --onedir --windowed --add-data "devsim_modules/;devsim_modules/" --icon=resources/icon.ico main.py
```
Исполняемый файл будет сгенерирован в директории `dist/main/main.exe`.

## 📈 Структура выходных данных
Программа генерирует стандартный текстовый файл параметров компактной модели (`.model` / `.subckt`), готовый для прямого импорта в:
*   **Tanner T-Spice / S-Edit** (Siemens EDA)
*   **Ngspice / Xyce** (Open-Source SPICE)

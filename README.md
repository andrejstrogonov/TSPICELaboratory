# TSPICE Laboratory

Настольное приложение на Python/PyQt6 для анализа характеристик кастомных транзисторов, оценки параметров компактной модели и экспорта карты SPICE.

## Что реализовано

- Переключаемые формы параметров для planar MOSFET, FD-SOI, FinFET, GAA nanosheet, GAA nanowire, TFET и HEMT.
- Импорт CSV с характеристиками Id–Vg, Id–Vd или C–V и отображение графиков.
- Аппроксимация Id–Vg MOS-структур методом `scipy.optimize.least_squares` для оценки `VTH0`, `U0` и `NFACTOR`; для FinFET/GAA учитывается эффективный периметр канала.
- Для TFET/HEMT расчёт метрик непосредственно по кривой: порог по постоянному току, `ION`, `IOFF`, `ION/IOFF`, подпороговый наклон и максимальная крутизна `gm`. Для HEMT также оцениваются sheet resistance и сопротивление доступа.
- Для Id–Vd оцениваются максимальный ток, `RON`, выходная проводимость `gds` и gate bias, если он задан.
- Оценка `CGG`, `CGSO` и `CGDO` по C–V данным с использованием введённых размеров прибора.
- Интерактивная 3D-схема транзистора с редактируемыми размерами структур и автоматическим вращением.
- Расчёт стационарного температурного поля методом конечных элементов (линейные тетраэдры) с оценкой `Tmax`, `ΔT` и `Rth`.
- Квазистатический 3D FEM-расчёт уравнения Лапласа для потенциала source/drain/gate с картой `|E|`. Отдельная карта магнитного поля оценивается аналитически по Biot–Savart.
- Решение разреженной FEM-системы на CUDA через PyTorch sparse conjugate gradient, если обнаружена CUDA-совместимая сборка PyTorch; иначе используется прямой CPU solver SciPy. Backend показывается рядом с результатами. Можно изменить разрешение сетки.
- Экспорт BSIM4 `.model` только для planar bulk MOSFET; для остальных структур экспортируется JSON-отчёт с параметрами и результатами, без заявления о совместимости с конкретной compact-моделью.
- Сохранение графиков в PNG/PDF.
- Отображение сведений GPU, если доступна команда `nvidia-smi`.

Моделирование на вкладке **3D / Тепло / Поле** собирает объёмную сетку из линейных тетраэдров и решает стационарную теплопроводность и квазистатическое уравнение Лапласа. Тепловая модель использует один коэффициент `k`, равномерный источник `Vds * Id` и фиксированную температуру на внешних гранях. Электрическая модель использует постоянную диэлектрическую проницаемость, граничные потенциалы source/drain/gate и не учитывает подвижный заряд. Магнитное поле — отдельная аналитическая оценка Biot–Savart для конечного прямого проводника, не FEM-решение уравнений Максвелла. Это упрощённые инженерные оценки, а не полная Maxwell/TCAD-модель; слои разных материалов, контактные сопротивления, электромиграция, временные эффекты и самосогласованная электрика-тепло не учитываются.

Экстракция параметров также использует аналитическую компактную зависимость или измеряемые curve metrics. Геометрические поправки для FinFET/GAA — приближение по периметру; TFET/HEMT не аппроксимируются BSIM4. Значения C–V являются упрощённой оценкой общей ёмкости и симметричных перекрывающих ёмкостей. DEVSIM, CUDA-ускоренное TCAD-моделирование и полноценная калибровка моделей для каждого семейства пока не реализованы.

## Установка и запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m src.main
```

Для разработки и запуска тестов:

```powershell
python -m unittest discover -s tests -v
```

GPU-индикация не обязательна для расчётов. Для неё установите совместимый драйвер NVIDIA и обеспечьте доступность `nvidia-smi` в `PATH`.

Для ускорения FEM на NVIDIA GPU установите сборку PyTorch с CUDA, соответствующую вашей системе и драйверу (команды для выбора сборки опубликованы на [официальной странице PyTorch](https://pytorch.org/get-started/locally/)). Установленный по умолчанию CPU-only PyTorch не использует видеокарту. Если CUDA недоступна, FEM автоматически работает на CPU; фактический backend указан в результатах расчёта.

## Формат CSV

Файл должен содержать заголовок; разделители запятая, точка с запятой и табуляция поддерживаются. Значения напряжения должны быть в вольтах, тока — в амперах, ёмкости — в фарадах.

Учебные CSV-примеры Id–Vg для всех семи семейств, а также Id–Vd и C–V находятся в [`data/examples`](data/examples/README.md). Образцы синтетические, но подходят для проверки интерфейса, экстрактора и экспорта.

```csv
Vg (V),Vd (V),Id (A)
0.0,0.05,1e-12
0.2,0.05,2e-10
0.4,0.05,1e-8
```

Для Id–Vg требуются столбцы `Vg` и `Id`; `Vd` задаётся отдельно для каждой точки или принимается равным 0.05 В. Для Id–Vd используются `Vd` и `Id`; при наличии постоянного столбца `Vg` он записывается как gate bias. Для C–V используйте `Vg` и `Cg` (допускается заголовок `capacitance`). Для экстракции нужно не менее пяти точек Id–Vg и трёх точек Id–Vd/C–V.
